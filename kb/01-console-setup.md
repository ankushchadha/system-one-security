# Console setup

## Power and start-up

1. Connect the power supply to the console and to a grounded outlet.
2. Press the power button on the front of the console. The status light turns green when the console is ready.
3. Start Tempo Swim on the setup laptop. With Auto Connect enabled, the console appears in the Available Consoles list within about 30 seconds.

If the console does not appear, check the Ethernet cable and the laptop's network adapter first. A link-local address (169.254.x.x) on the adapter is normal here, because the link is a direct cable with no router.

## Pool configuration

Open Settings, then Pool. Set the number of lanes and which ends have pads. For this pool that is 8 lanes, start end only. Setting turn-end pads that are not wired makes the console wait for touches that never arrive.

Set the course to match the pool. A wrong course setting changes the event list and split distances, not the timing itself.

## Arming lanes

Each lane must be armed before a race. An unarmed lane records nothing, even when the swimmer touches the pad. The run screen shows armed lanes with a filled marker. Arm all lanes from the run screen with the Arm All key, or one lane at a time.

## Backup buttons

Each lane has three backup buttons (A, B, C) held by timers on deck. If a pad touch is missed, the console uses the backup buttons to fill the time. Two of three buttons must be pressed for a backup time to be accepted.

## Saving a race

After the last swimmer finishes, press Save, then Reset. Times are only available to the results laptop after Save. Pressing Reset without Save discards the race.
